# Delivery evidence

Use only recorded evidence. Mark missing checks `not_tested`.

- Target: store, local path, Theme ID, verified role, preview/editor URLs.
- Change: business outcome, files, settings, dependencies, excluded scope.
- Validation: Schema, locale, SEO, Markets, performance, accessibility, functional, visual.
- Operations: merchant setup, known limitations, rollback, safe next action.
- Safety: live theme targeted, published, store data modified, sensitive data removed.
