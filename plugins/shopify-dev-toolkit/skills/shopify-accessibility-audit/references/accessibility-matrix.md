# Accessibility matrix

- Keyboard: tab order, visible focus, skip link, escape, focus return, no keyboard trap.
- Structure: landmarks, headings, lists, tables, dialogs, menus, form grouping.
- Names: labels, button/link names, icons, image alternatives, error association.
- Dynamic UI: drawers, modals, predictive search, variants, cart updates, live regions.
- Visual: text and UI contrast, 200% zoom, 320 px reflow, reduced motion, target size.
- Test representative home, product, collection, search, cart, and affected templates.
