# Theme Editor guide checklist

- Exact template, section, block, and visible UI labels.
- Prerequisites: App, product/collection, metafield, metaobject, market, locale.
- Add, configure, reorder, hide, disable, and remove steps.
- Defaults, valid ranges, recommended values, limits, and device behavior.
- Preview verification, common errors, fallback, and recovery.
- Clearly mark unverified store-specific steps and never instruct publication.
