# Capture matrix

- Pages: home, representative product, collection, cart, and the directly affected template.
- Viewports: 320, 390, 768, 1024, and 1440 px as relevant.
- States: default, hover/focus, open drawer/modal, selected variant, populated and empty cart.
- Stabilize: animations, video, carousel autoplay, random values, timestamps, consent banners, personalized apps.
- Evidence: matched baseline/changed screenshots, viewport, URL, market, language, and difference classification.
