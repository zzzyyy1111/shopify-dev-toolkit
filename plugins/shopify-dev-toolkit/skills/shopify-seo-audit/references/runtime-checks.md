# Runtime SEO checks

- Rendered title, description, canonical, robots, H1, status code, and indexable URL.
- Hreflang reciprocity, language-region codes, self-reference, and canonical compatibility.
- Product JSON-LD price, currency, availability, URL, variant, ratings, and visible-page agreement.
- Breadcrumb, Organization, WebSite, Article, and duplicate JSON-LD sources.
- Pagination, filters, search, 404, image alt, internal links, redirects, and Markets URLs.
- Separate theme output from Shopify platform output, store content, apps, and settings.
