# Preview testing checklist

## Core pages

- Home page.
- Representative one-variant and multi-variant products.
- Sold-out or partially unavailable product.
- Representative collection.
- Search results when affected.
- Cart drawer and cart page.

## Core behavior

- Verify variant selection, price, media, availability, and URL updates.
- Verify Add to cart, quantity, cart update, remove, and totals.
- Verify dynamic checkout and nearby App blocks.
- Verify navigation, search, drawers, modals, and accordions.
- Confirm no new console errors and relevant network requests succeed.

## Responsive and visual

- Test relevant 320, 375/390, 768, 1024, and 1440 pixel widths.
- Check overflow, wrapping, image ratio, fixed elements, focus, and layout shift.
- Compare against the baseline theme using the same data and UI state.

## Theme Editor

- Add, remove, hide, and reorder affected sections or blocks.
- Change relevant settings.
- Confirm JavaScript survives section reload and unload.
- Confirm schema, locale, and App blocks render without errors.

## Handoff

Record preview/editor URLs, theme ID and role, tested pages, results, screenshots, remaining checks, and `Live theme unchanged`.
